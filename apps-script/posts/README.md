# 공연 소식 · 갤러리 서버 설치 (10분)

대표님이 홈페이지를 직접 고칠 수 있게 하는 작은 서버입니다.
구글 계정만 있으면 공짜로 돌아갑니다. 이거 하나로 **두 가지**를 하십니다.

- **공연 소식** — 제목 · 날짜 · 내용 · 사진 여러 장
- **무대의 기록(갤러리)** — 첫 화면 사진 더하기 · 빼기 · 순서 바꾸기 · 설명 고치기

이 설치는 **구글 계정에 로그인해야 해서 큰길브리지가 대신 못 합니다.**
아래 순서대로 한 번만 해주시면 됩니다.

---

## 1단계 — 스크립트 만들기

1. <https://script.google.com> 접속 → **새 프로젝트**
2. 프로젝트 이름을 `아이엠매직 공연 소식` 으로 바꿉니다 (왼쪽 위 「제목 없는 프로젝트」 클릭)
3. 화면에 있던 코드를 **전부 지우고**, 이 폴더의 `Code.gs` 내용을 **전부 붙여넣기**
4. 저장(💾)

## 2단계 — 비밀번호와 열쇠 넣기

왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성** → **속성 추가** 3번

| 속성 이름 | 값 |
|---|---|
| `UPLOAD_PW` | 관리자 비밀번호 — 대표님이 정하신 값 (소식·갤러리 둘 다 이 비밀번호를 씁니다) |
| `GITHUB_TOKEN` | 아래 3단계에서 받는 토큰 |
| `GITHUB_REPO` | `brizymedia/immagic` ← 그대로 적으세요 |

> ⚠️ 이 값들은 **카톡·메일로 보내지 마세요.** 이 화면에만 넣으면 됩니다.

## 3단계 — 깃허브 토큰 받기

1. <https://github.com/settings/personal-access-tokens/new> 접속 (brizymedia 계정)
2. **Token name**: `immagic-posts`
3. **Expiration**: `No expiration` (또는 1년)
4. **Repository access**: `Only select repositories` → **immagic** 선택
5. **Repository permissions** → **Contents** 를 **Read and write** 로
6. 맨 아래 **Generate token** → 나온 `github_pat_...` 값을 복사해
   2단계의 `GITHUB_TOKEN` 에 붙여넣기

> 토큰은 그 화면을 벗어나면 다시 못 봅니다. 바로 붙여넣으세요.

## 4단계 — 배포하기

1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴 → **웹 앱**
3. 설정
   - 설명: `v1`
   - 다음 사용자로 실행: **나**
   - 액세스 권한: **모든 사용자** ← ⚠️ 「Google 계정이 있는 모든 사용자」 아니라 **모든 사용자**
4. **배포** → 권한 요청이 뜨면 승인
   (「이 앱은 확인되지 않았습니다」 가 나오면 **고급 → 안전하지 않음(이동)** 을 누르세요. 직접 만드신 앱이라 괜찮습니다.)
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`) 을 복사

## 5단계 — 주소 알려주기

그 `/exec` 주소를 **큰길브리지(1533-7295)에 직접 불러주세요.**
홈페이지 관리자 화면에 박아 넣으면 바로 쓰실 수 있습니다.

(급하시면 관리자 화면 `news-admin.html` 의 「서버 주소」 칸에 직접 붙여넣어도 됩니다.
그 경우 이 브라우저에서만 기억됩니다.)

---

## 권한 오류가 날 때

「UrlFetchApp.fetch를 호출할 수 있는 권한이 없습니다」 가 뜨면:

1. 편집기 위쪽 함수 목록에서 **권한받기** 를 고르고 **실행**
2. 권한 창이 뜨면 승인
3. **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**

설정이 제대로 들어갔는지 보려면 함수 목록에서 **점검** 을 실행하고
아래 **실행 로그** 를 보시면 됩니다.

## 코드를 고쳤을 때

**배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** 를 해야 반영됩니다.
「새 배포」를 누르면 **주소가 바뀌니** 누르지 마세요.

---

## 어떻게 돌아가나 (참고)

```
관리자 화면(news-admin.html)  ─ 탭 두 개
   │  ① 사진을 긴 변 1600px 로 줄여서 한 장씩 보냄
   │  ② 글 / 갤러리 목록을 보냄
   ▼
이 서버 (앱스 스크립트)
   │  깃허브 토큰으로 저장
   ▼
brizymedia/immagic 저장소의 photos 가지
   ├─ posts/posts.json        ← 소식 글 목록      → news.html 이 읽음
   ├─ posts/p1a2b3c-001.jpg   ← 소식 사진
   ├─ gallery/gallery.json    ← 갤러리 칸 목록    → index.html 이 읽음
   └─ gallery/g1a2b3c-001.jpg ← 갤러리 사진
```

갤러리 칸 하나는 `{ f: 사진경로, c: 설명, n: 이름 }` 입니다.
`f` 가 `assets/` 로 시작하면 홈페이지에 원래 있는 사진이라 서버가 손대지 않고,
`gallery/` 로 시작하면 관리자 화면에서 올린 사진입니다.

- **홈페이지(main 가지)는 건드리지 않습니다.** 글을 올려도 사이트가 다시 배포되지 않아
  바로바로 반영됩니다(최대 5분).
- 사진 원본은 올라가지 않습니다. 긴 변 1600px 사본만 저장됩니다.
- 글은 최근 120개까지, 갤러리는 40칸까지 둘 수 있습니다.
- 갤러리에서 뺀 사진은 「저장하기」를 눌렀을 때 파일까지 지워집니다
  (홈페이지에 원래 있던 `assets/` 사진은 지우지 않습니다).
